# 原生 DFT 参考查询

按 [查询指南](../../knowledge/reference/QUERY_GUIDE.md) 选择最小资料。参数问题先查 [参数索引](../../knowledge/reference/params/INDEX.md)，文件问题查 `knowledge/reference/files/`，概念与组合问题查 `topics/`，PW/PWRS 范围查 `modules/`。混合任务先回当前工作流定位阶段。

回答精确键名、类型、单位、默认值、条件覆盖及适用范围；默认值与物理推荐值分开。包内资料是已核对的兼容性快照，不能作为所有 PASP.x 版本的功能承诺。发行资料或实际输入/回显不一致时保留证据，不能猜枚举或把旧拼写自动视为别名。

只以用户可获得的执行文件配套资料、输入输出和本包为使用依据，不要求源码、源码路径、编译工具或开发仓库。不反编译或从可执行文件字符串推测功能。未公开的实空间预处理选项只提供允许的调用设置，不解释算法或赋予固定名称。

未查到精确字段时明确资料缺口，保留用户原设置；不能借用 VASP/QE 或其它 PASP 模型的同名参数。参考查询可以直接完成；若委派，只提供有界事实查询，使用 [只读核查](../pasp-dft-verifier/skill.md)。
