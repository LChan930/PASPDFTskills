# 参数名称与版本兼容性

本页是随技能打包的参数知识快照（2026-11-16），不是官方兼容性清单。用户持有的 `PASP.x` 可能不同；以该版本的发行手册、配套示例和实际日志确认。不要求源码，也不通过私有实现或二进制检查确认接口。输入中出现某键、程序未报错，都不能独立证明它产生了预期效果。

| 参数 | 本参考中的用户含义 | 输入建议与边界 |
| --- | --- | --- |
| `DFT.LPRECOND`，默认 F | 旧输入中可能出现的预条件相关标签；不是本参考的 PWRS 实空间预处理接口 | 不加入新的实空间预处理输入，不把它解释为默认加速总开关。已有输入保留原意并提示兼容性待核查。`DFT.RS.DENSITY_FFT_BOX` 的参考限制要求它为 F，故也不能声称它在任何组合下均无作用。 |
| `DFT.RS.PRECONDITIONER`，默认 0 | PWRS实空间预处理选项选择；默认0，其他值按版本确认 | 按[磁场与预条件](magnetic-preconditioning.md)和版本资料检查模式及限制。不能通过同时打开 LPRECOND 扩大支持范围。 |
| `DFT.PWL.n0`，默认 1 | `DFT.Bfield T` 时的沿 a3 磁通量子数 | **不是过时参数**。默认值代表非零磁通；0 为磁分支中的零通量，不能等同关闭 Bfield。保留用户有意选择。 |
| `PWL.nx`、`PWL.ny`、`PWL.nz`、`PWL.n0` | 历史 PWL 输入名称，与当前参考的 PWRS 输入不同 | 不加入新 PW/PWRS 模板；不能用 `PWL.n0` 替代 `DFT.PWL.n0`，也不能用旧网格键替代当前密度截断或受限显式网格设置。旧输入应先确认其目标版本与模型。 |
| `PWL.linputV`、`PWL.inputV_tau` | 历史名称，本技能未给出可移植支持承诺 | 不生成。`DFT.inputV` 是独立的特殊外势任务选择，不能仅按名字迁移旧输入。 |
| `DFT.mixing`、`DFT.mixing_mag`、`DFT.mixing.method`、`DFT.mixing.Pulay_m` | 普通 DFT 混合控制 | 不因旧输入也使用这些名字就归入旧 PWL 专用项；按[核心参数](../params/input-parameters-core.md)确认方法与条件。 |
| `DFT.ALGO`、`DFT.RS.kinetic`、`DFT.RS.vnl` | 求解器与表示相关控制 | 完整 PWRS 参考限制为 ALGO=4，并将 kinetic/vnl 设为 T。不要从历史 PWL 示例推断当前 PWRS 支持其他求解器。 |

本参考的模式4组合涉及规范限制，但没有提供可移植的规范选择输入键。不要猜造 `PWL.gauge`、`DFT.PWL.gauge` 或其他键；需要不同规范时先取得该发行版本的明确使用说明。

审计旧输入时逐项列出参数、原有意图、版本证据、已知限制与待确认项；迁移只改变获得授权的设置。出现 `NUMERICAL_FAILURE` 等状态时，依据实际输入和日志的首个失败信息分析。旧名称或不确定参数本身不能证明是某次数值失败的原因；参见[验证与报告](validation.md)。
