# Graphene：零磁通与有限磁通：历史运行与证据笔记

记录日期：2026-11-17。此页是历史案例定位，不是当前运行证明、材料默认值或新计算授权。

本次控制器新审计已定位两分支TB.bands；SCF/bands的Bfield/n0分别匹配T/0、T/1，四份日志正常结束；电荷积分均为8e。新观察替代旧盘点“缺TB”的结论，但不把正常退出单独升级为电子/谱收敛。当前只有有限磁通SCF提供CRTCAR；其他阶段缺电流数据不能生成虚构电流图。此模板仍仅输入派生，没有在构建中启动新运行。

本次审计另核对两条SCF分别在82/68次电子迭代结束，低于NELM200，末次带能变化约7.97e-8/3.37e-8 Ha，匹配请求EDIFF1e-7；重启记录为LEGACY_CONVERGED。这是匹配历史产物的legacy证据，不是本模板新算出的测试证书。两份TB均为5带、200路径样点，且K点未显式采样，路径间隙不能作为Graphene基本带隙。有限磁通SCF与band密度不是逐字节同一份，但各自元数据配对合法；不能把它们默认为刚运行同一次SCF的原样拷贝。

## 本包实际完成的检查

本包标记为 `input-derived / not-runtime-tested`：输入与实际引用结构来自现有案例，构建时只作静态闭包和哈希检查，没有启动 PASP 或 MPI。目录中已有历史输出不能自动升级本模板的证据等级。历史测试、当前输入静态检查、本次实际运行三者分别记录。所有 UPF 因再分发权限未明确而不随包分发，必须由用户合法提供；没有 UPF 时不具备运行完整性。

模板FDF和所有被引用结构按原字节复制，依赖manifest保留逐文件哈希与UPF头元数据。UPF未附，不复制CHGCAR、.restart、PLUS_U_NS、PASP.used_info、TB.bands、output_MD.dat、锁或旧日志。本包的完成不表示任何材料已收敛；真正运行结果应在用户目录留独立报告。
