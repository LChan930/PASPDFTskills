# 已有输出：日志、能带、能级、DOS 与 MD：状态机

从用户当前文件与意图定位S0–S7，不要求已完成阶段重做。只加载[教程](output_analysis.md)中当前阶段；[历史案例](output_analysis_run_notes.md)不能替代本次证据。

| 状态 | 本路线要完成的具体事实 | 转移条件 |
| --- | --- | --- |
| S0 | 按内容识别用户已有日志、固定晶胞弛豫、谱、DOS 或 MD | 记录实际输入、产物和来源后进入下一状态。 |
| S1 | 只读文件哈希、配对来源与缺失项 | 缺证据留在本状态，记录missing/unknown；不要编造补齐。 |
| S2 | 选分析对象、输出目录与表号 | 记录实际输入/产物与来源后进入下一状态。 |
| S3 | 单位/参考/占据/自旋/权重与语言 | 记录实际输入/产物与来源后进入下一状态。 |
| S4 | 核对解析格式与命令选项，无输入晋级要求 | 缺证据留在本状态，记录missing/unknown；不要编造补齐。 |
| S5 | 执行已授权本地分析，写用户新产物 | 记录实际输入/产物与来源后进入下一状态。 |
| S6 | 核对JSON、图/计数/单位与原始证据一致 | 缺证据留在本状态，记录missing/unknown；不要编造补齐。 |
| S7 | 交付报告图、来源、unknown和限制 | 记录实际输入/产物与来源后进入下一状态。 |

S4预检将当前输入/include/UPF/重启依赖、物理设置、发行兼容和资源逐项落到具体文件。适用时按[本地verifier契约](../../subskills/pasp-dft-verifier/skill.md)做有界只读复核；控制器仍负责解释与写入，不把授权反复重问。预检失败留候选与缺项，不把它称作可提交输入。输出分析路线的S4是数据解析预检，不制造输入晋级门槛。

S5材料运行仅在已有任务授权覆盖实际执行时进行；仅要求输入/教程/分析时不擅自启动PASP。已有授权的读取、可逆编写和本地分析直接完成。缺关键科学选择时只问所缺信息，不复制上游其他物理模型的确认标记。S6失败时保留日志和产物，结论标失败/未知，不晋级为validated/handoff-ready。

每个关键目录的PROGRESS至少记录：Status、Route/Branch/Stage、输入和依赖哈希、已接受设置、实际命令与ranks、上游来源、Gate evidence、缺失项、允许的下一步。结束状态可以是input-ready-with-missing-UPFs、output-validated或blocked-by-real-data；这三者不能互称已运行成功。
